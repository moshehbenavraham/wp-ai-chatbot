# Session 03: Context Pack and Decision Log Templates

**Session ID**: `phase00-session03-context-pack-decision-log-templates`
**Status**: Not Started
**Estimated Tasks**: ~12-18

## Objective

Create reusable templates for bounded context packs, decision logs, and carry-forward notes so future sessions can execute with consistent structure and traceability.

---

## Scope

### In Scope (MVP)
- Define context pack template sections and required source anchor citations.
- Define decision log format for "adopt as-is" versus "adopt with modifications".
- Define carry-forward note structure for unresolved conflicts and assumptions.

### Out of Scope
- Populating templates with complete phase data.
- Approving final cross-phase decisions.

---

## Deliverables

1. Context pack template with bounded-input rules and anchor requirements.
2. Decision log template with rationale and impact fields.
3. Carry-forward template for unresolved items and mitigation tracking.

## Success Criteria
